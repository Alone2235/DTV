# DTV 体感与逻辑审计（UX + Logic Audit）

> 目的：把"明明还可以但说不上来哪里怪"变成**可勾选、可排优先级、可验收**的清单。
> 方法：每条 = 现象 → 用户感受 → 修法 → 工作量。仅记录，先不改代码。
> 依据：真机截图 + 源码走查（2026-11，2.26 版本）。

---

## 一、首页（MainActivity / activity_main.xml / VideoGridAdapter）

| # | 现象 | 用户感受 | 修法 | 量 |
|---|---|---|---|---|
| H1 | 卡片**纯封面无标题**，一屏 20 张图 | "全是图，不知道哪个是哪个" | 改**分排货架**：行标题（推荐/美食…）+ 5 张/排横向滚动 | 中 |
| H2 | **顶部标题/计数** + **底部信息栏** = 两条信息带 | 眼睛上下跑，没有落点 | **砍掉底栏**；信息只在焦点卡浮层显示（就近原则） | 小 |
| H3 | 切分类 `notifyDataSetChanged()` **整屏全刷** | "闪一下，很糙" | 换 `DiffUtil`/局部刷新 + 内容**淡入 160ms** | 小 |
| H4 | 加载/空/错三态**只有一行文字**（已见：2483 + 重试） | "像没做完" | 统一 `StateLayout`：**骨架屏 / 品牌加载 / 空态插画+主按钮** | 中 |
| H5 | 冷启动 **黑屏几秒**（无骨架） | "卡了？" | 骨架屏（骨架网格，8 张灰块）+ 上次内容缓存 | 中 |
| H6 | 侧栏 **icon-only 无文字/无提示** | "这几个图标是啥？不敢点" | 聚焦时**在图标旁显示名字**（小气泡/标签） | 小 |
| H7 | 分类 chips **一排 10 个** | 顶部拥挤 | 默认露 6-7 个 + "更多"折叠 | 小 |
| H8 | 错误提示**暴露接口码**（status_code=2483） | "这啥？看不懂" | 码 → **人话**（"抖音登录已过期"）+ 一键去重新导入 | 小 |
| H9 | 刷新后**焦点可能丢失**（回不到原卡） | "怎么跳走了" | 记录 position，刷新后恢复焦点 | 小 |
| H10 | 封面颜色杂乱、无降噪 | "看着累" | 封面统一**轻微降饱和 + 暗角**；邻卡压暗 20-30% | 小 |

## 二、播放器（PlayerActivity，1409 行）

| # | 现象 | 用户感受 | 修法 | 量 |
|---|---|---|---|---|
| P1 | **清晰度固定/偏低**，无档位可选 | "糊" | 档位列表（接口返回的 qn）+ **设备解码能力过滤** + 上限预设 + 记忆 | 大 |
| P2 | 控制栏一堆**文字按钮** | 乱、挡画面 | 压成三层：标题/进度同行 + L2 图标+文字 + L3 纯图标 | 中 |
| P3 | 卡顿/失败要**用户自己切线路/引擎**（技术黑话） | "我不懂" | **自动降级链**：线路→引擎→清晰度，界面只说"正在换线路" | 中 |
| P4 | 续播有实现但**无提示** | "怎么从这里开始？" | 起播轻提示"从 12:30 继续" | 小 |
| P5 | 播放失败**无明确出口** | "黑屏了怎么办" | 错误态：原因人话 + 重试 + 换线路 | 小 |
| P6 | 快捷键（数字键 5=点赞）**无提示** | 不知道有 | 首次提示一次 / 菜单里标注 | 小 |
| P7 | 手机推送播放**无来源提示** | 不知谁推的 | 标题旁"来自手机"角标 | 小 |
| P8 | 菜单弹出/收起**是否硬切**（待核） | "生硬" | 位移+透明度 220ms 进出 | 小 |

## 三、逻辑与架构（"稀碎 bug"的根）

| # | 现象 | 影响 | 修法 | 量 |
|---|---|---|---|---|
| L1 | **命令路由写 4 遍**（ConfigServer / WSServer / ExternalActions / Player） | 改一处忘一处 → A 对 B 错 | 抽 `Command.kt` 单一路由器 | 中 |
| L2 | 状态散落在 Activity 的 `lateinit` + 手动 findViewById | 选中态↔内容↔标题不同步 | 每页单一状态源（State 对象） | 中 |
| L3 | 三态（加载/空/错）各自手写 | 有的有有的没 | 统一 `StateLayout` 组件 | 中 |
| L4 | 错误处理各自为政（Toast/静默/接口码） | 行为不一致 | 统一错误映射（码→人话→动作） | 小 |
| L5 | **Cookie 过期无自愈** | 直接不能用 | 拦 2483/风控码 → 引导重新导入 | 中 |
| L6 | 系统组件残留（Toast 5 / Dialog 7 / 进度条 20 / emoji 36） | "廉价感" | 按守卫基线逐个替换 | 中 |

## 五、优先级建议

| 级别 | 条目 | 理由 |
|---|---|---|
| **P0（决定能不能用）** | L5 Cookie 自愈 · P1 清晰度分档 · P3 自动降级 · **遥控器修通** | 不做用户直接流失 |
| **P1（决定"顺不顺"）** | H1 分排货架 · H2 砍底栏 · H3 局部刷新·淡入 · H4/H5 三态+骨架 · P2 菜单压缩 | 一次解决"发懵/闪/糙" |
| **P2（工程健康）** | L1 统一路由 · L2 状态源 · L3 StateLayout · L4 错误映射 | 根治"稀碎 bug" |
| **P3（打磨）** | H6-H10 · P4-P8 · 系统组件收尾 · 手机端收敛 | 完成度 |

> 顺序建议：**P1 里挑「H2+H3+H4」（砍底栏 + 局部刷新 + 三态）一次做完** —— 半天到一天，首页的"发懵/闪一下/像没做完"会同时消失，性价比最高。
