# DTV 设计规范（UI 唯一依据）

> 本文汇总项目所有 UI 要求与已定稿结论。**任何界面改动先对照本文**；
> 原型预览（可交互）：`docs/preview/index.html` —— 改设计先在原型里看，通过后再落到代码。

---

## 〇、品牌标识

| 项 | 电视端 | 手机端 |
|---|---|---|
| 容器 | 深色圆角方块（≈squircle） | 深色圆角方块（同） |
| 底色 | `#0E0E13` | `#0E0E13`（同） |
| 图形 | **音符**（内容语义） | **遥控器**（控制语义，倾斜 20°、图案偏小） |
| 笔画 | 白色实心 | 白色实心（同） |

**家族规则**：容器形状 / 配色 / 笔画风格 / 留白比例**完全一致**，仅**图案**区分端 —— 一眼看出是一家，又能分清哪个是哪个。

**已否决的方案**（勿再用）：
- ❌ 红色圆形 + 播放三角（容器与配色和电视端不一致）
- ❌ 白色**十字**图形（中文语境易联想十字架，不吉利）
- ❌ 竖直胶囊机身（看起来像插排 / USB 棒）
- ❌ 两端用同一图案（曾误把电视端音符覆盖成播放三角 —— 项目已有品牌资产**先查再做**）

**应用名**：电视端 `DTV`、手机端 `DTV 遥控器`（开源项目名避免直接写"抖音"以规避商标风险；功能说明中可写"抖音 TV 客户端"）。

## 一、设计 token（两端共用，单一来源）

```
颜色
  品牌强调  #FE2C55（仅用于：选中态 / 主操作 / 指示条）
  背景      #0A0B0F  极简深蓝黑，无彩色渐变
  面板      #14141A
  控件      #23232E
  正文      #FFFFFF   次要 #9A9AA8   三级 #5A5A6A
  描边      rgba(255,255,255,.10)

栅格：8px 基准（半格 4）
  手机端  页边距 18 / 组内 8-10 / 组间 24
  电视端  安全区 16 / 卡片间距 8（防老电视过扫描切边）

字阶（含行高）
  手机端  22 / 17 / 14 / 12 px   行高 1.4
  电视端  32 / 24 / 18 / 16 px   行高 1.3（3 米可读，正文最低 18）

圆角
  手机端  面板 16 / 控件 10
  电视端  面板 20 / 控件 12
  —— 圆角**不宜过大**（曾用 24/28 被否）

控件高度  56px（按钮 / 输入框 / 键位统一）

动效：三档 160 / 240 / 320 ms
  手机端 spring dampingRatio 0.6-0.65（"生命感"，不要过度弹跳显廉价）
  电视端 140ms 干脆（远距离观看要快）
```

## 二、液态玻璃（手机端）

- **三件套**：折射 + 轻模糊 + **边缘高光描边**；纯模糊 = 厚毛玻璃，**已否决**
- 磨砂要轻：模糊 6-9dp；着色 alpha≈0（要通透）
- 玻璃边界必须有**描边**（否则糊进背景）
- **两端质感必须统一**（圆角 / 描边 / 磨砂参数一致）
- 跟手高光：**要有轮廓（像被按下的按钮）**，不是一团弥散光晕
- 背景：极简深色，**不加彩色渐变、不加底部径向光晕**（已否决）
- ⚠️ 规范警告：过度透明会伤害文字可读性 → 文字下要有对比保障

## 二·五、主次层级（强制规则）

**一屏只允许一个主角。** 每屏落地前自检：
> 这屏的主角是哪个？其余元素是否都已降级？如果找不出唯一主角 → 不合格。

| 层级 | 用法 | 视觉 |
|---|---|---|
| **L1 主操作**（每屏仅 1 个） | 播放 / OK / 配对 / 扫描 | 品牌色 `#FE2C55` 实心 + 尺寸最大（+6~10px）+ 白字 |
| **L2 次操作** | 上一条 / 下一条 / 普通按钮 | 中性面板 `#23232E` + 常规尺寸 + 白字 |
| **L3 辅助操作** | 返回 / 菜单 / 图标按钮 | 透明底或仅描边 + 次要色 `#9A9AA8` |
| **L4 三级信息** | 作者 / 播放量 / 版本号 | 12px + 三级色 `#5A5A6A` |

**空间也承担主次**：组间 24 > 组内 8-10；主角周围留白最大。

**当前违规点（待修）**：
- 手机遥控页：触控板是无语义的大面积空白，视觉重量却超过主角播放键 → 需弱化（淡描边 + 中央提示，去掉四角标记的抢眼程度）
- 手机设备页：一屏 **8 个同级元素**（标签/输入框/3 个同权按钮/列表/配对标题/输入框/按钮）→ 无主角，需重构为「已连接设备卡片（主）+ 一个主按钮 + ⋮ 收纳其余」
- 手机工具页：6 个同权文字按钮 → 维护类全部进 ⋮

## 三、排版规则（重点，曾是最弱项）
1. **一屏一个信息焦点**：电视端视频卡片**只显示封面**（+右下角时长角标），标题/作者/播放量**只在焦点项的信息栏**出现 —— 常驻 10 条标题 = 文字噪音，已否决
2. **文字单行省略**：标题/元信息一律 `nowrap + ellipsis`，写不完就省略号，**不换行撑高卡片**
3. **网格列等宽**：CSS/布局用 `minmax(0,1fr)` + `min-width:0`（否则 nowrap 文字会让列宽不等、封面大小不一）
4. **单一左对齐轴**：整页元素贴同一条基线
5. **分组用容器/分隔线**划边界，不靠空白
6. **主次分明**：一屏只有一个主操作（品牌色 + 大一号），其余用次要色
7. **图标与文字基线对齐**（图标 24dp 时文字行高 24dp）

---

## 四、图标规则

- **禁止 emoji / 文字当图标**（曾用 `⋮`、`⏮▶⏭`、`👍⭐💬`，全部已否）
- 一律用 **矢量图标**：统一 24dp 网格、2dp 描边或白色实心笔画
- 有公认图标的动作**一律用图标**：搜索 / 设置 / 刷新 / 返回 / 更多 / 扫描 / 连接 / 更新
- 文字只做辅助（11-12px）

---

## 五、导航与信息架构

- **一步到位**：拒绝"我的"这类把功能堆一起的聚合页（已否决）
- **低频 / 破坏性操作进二级菜单**（`⋮` 溢出菜单）：断开连接、电视设置页、检查更新、APK 升级
- 手机端 5 个 Tab：遥控 / 设备 / 工具 / 设置 / 方向
- **方向键功能保留但独立成页**，不占遥控页位置（已定稿）
- 电视端用**左侧边栏**（不是底部 Tab）；侧边栏 76-88px、图标 + 小字
- 电视端**去掉与侧边栏重复的分类 Tab**（同一件事不要两层表达）

---

## 六、手势与动效

- **Tab 可左右滑动切页**：跟手连续（页面位移 + 指示条同步），松手吸附最近页，带 Q 弹回弹
- **方向锁定**（关键）：横滑 = 切 Tab，竖滑 = 切视频，**首帧方向决定，绝不打架**
- 触控板：单击暂停 / 双击点赞 / 上下滑切视频 / 左右滑翻页
- 电视端焦点态：**2dp 品牌色描边 + 轻微放大（1.03-1.04）**，**不要外发光**
- 电视端禁止依赖悬停/长按，全部 D-pad 可达

## 九、新增 UI 检查清单（每次加/改页面前必须过一遍）

**A. 动手前**
- [ ] 读原实现（Activity + layout + 注释），列进 `docs/CAPABILITY-AUDIT.md`，确认新设计是**超集**
- [ ] 在原型（`docs/preview/`）里先画出来，改完刷新确认

**B. 用组件，不要用系统默认**
- [ ] 提示 → `CustomToast`（禁用 `Toast.makeText`）
- [ ] 对话框 → `GlassDialog`（禁用 `AlertDialog.Builder`）
- [ ] 加载 → `BrandLoading`（禁用 `ProgressBar/ProgressDialog`）
- [ ] 输入框 → 自绘输入框（禁用裸 `EditText`）
- [ ] 图标 → 矢量图标（**禁用 emoji / 文字当图标**）

**C. 只用 token，不写字面量**
- [ ] 颜色 → `colors.xml` / `Tokens.kt`（禁 `Color.parseColor("#…")`、禁 XML 里 `#RRGGBB`）
- [ ] 尺寸 → `dimens.xml` / `Tokens`（8px 栅格：4/8/16/24/32/48）
- [ ] 字号 → 四级字阶（手机 22/17/14/12；电视 32/24/18/16）
- [ ] 圆角 → 面板 16-20 / 控件 10-12

**D. 结构与层级**
- [ ] 一屏只有 **1 个 L1 主操作**
- [ ] 文字**单行省略**（不换行撑高）
- [ ] 电视端卡片**纯封面**，标题只在焦点信息栏
- [ ] 分组用容器/明度差，不用粗描边
- [ ] 焦点态 = **2dp 品牌描边**（不要光晕）
- [ ] 左右边距**对称**、贴同一条对齐轴

**E. 动效**
- [ ] 进/出场：260-320ms；对话框 220ms（带轻微过冲）
- [ ] 卡片交错 24ms；列表项交错 50ms
- [ ] 手机端 spring damping 0.6-0.65；电视端 140ms 干脆
- [ ] 每个操作都有反馈（Toast / 状态变化 / 图标动画）

**F. 提交前**
- [ ] 跑 `./tools/design-guard.ps1` —— **不允许新增违规**（CI 也会跑）
- [ ] 改动了原有能力 → 同步更新 `docs/CAPABILITY-AUDIT.md`
- [ ] 更新 `CHANGELOG.md` + 版本号（十进制小进位）
